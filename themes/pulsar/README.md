# Pulsar — dark landing theme for Cleitext

A dark landing theme for software and hardware projects, built on Aurora: gradient hero, terminal blocks, feature grids and download sections. Pages are made of normal blocks with `psx-*` CSS classes (block sidebar → *Advanced* → *Additional CSS class*); AI assistants connected through MCP read its guide (`src/guide.ts`).

Install it from **Appearance → Themes → Add New** (Cleitext catalog), or build and install it from this folder:

```bash
cleitext theme:install themes/pulsar --build
```

# Taccuino Blocks

The blocks that come with the **Taccuino** theme (installed and activated with it): **Articles** (the latest
articles, the first over its photo, then cards, with a list for phones and a "load more" link) and **Embeds of
articles** (the players saved in a field of the latest articles of a category, as a colored band or a list).
They use the theme's markup and styles, in the block editor and in Fresco. See the theme's README.
